# Sistema POS El Buen Sabor

Sistema web para la gestión de pedidos y ventas de una hamburguesería.

## Tecnologías utilizadas

- ASP.NET Framework
- SQL Server
- HTML
- CSS
- JavaScript

## Prueba de GitHub Codespaces

Este cambio fue realizado para demostrar el uso de GitHub Codespaces como plataforma de desarrollo en la nube.
